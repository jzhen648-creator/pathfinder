# Audit — code & decision docs (2026-07-13)

Scope: contradictions between decision documents, drift between docs and code, and unconventional patterns that could cause issues. Ground truth for "which doc is right" is the code at `3a329f9`; ground truth for "what was decided last" is git history. Doc fixes shipped alongside this report are listed in §6; **no code was changed**.

---

## 1. Executive summary (top risks first)

1. **Vercel crons target routes that don't exist.** `vercel.json` schedules `/api/cron/cleanup-stream-runs` (daily) and `/api/cron/map-health` (weekly), but there is no `src/app/api/cron/` directory, and `verifyCronRequest` (`src/lib/cron-auth.ts`) has zero callers. Middleware would also 401 the requests (only `/api/health` is public). Both jobs have silently failed since the desktop-schema drop. → Remove the cron entries or reinstate the routes.
2. **The unit test suite requires a live database.** `src/lib/ai/generate-reflect.ts:345` (`loadPursuitSignals`, added in `08796cf`) calls `prisma.goal.findMany` inside a code path the tests exercise, and `generate-reflect.test.ts` mocks everything *except* Prisma. On a fresh clone, 6 tests fail; locally they only pass because `.env.local` points at the dev Supabase instance. Unit tests reading a real database are flaky and can mutate shared QA data. → Mock `prisma` in the test (or inject the loader).
3. **A fresh clone cannot build or test at all.** `prisma.config.ts` throws when `DATABASE_URL` is unset, which makes `prisma generate` (a pure codegen step) fail — so `npm install`'s postinstall fails silently, and `tsc --noEmit` + `npm test` produce ~30 cascading failures until an env file exists. → Make the `DATABASE_URL` check lazy (only for commands that need a connection).
4. **Ops scripts referenced by docs are broken.** ~10 scripts under `scripts/` still query dropped tables (`Mark`, `StreamRun`, `StreamSession` — dropped in `20260621120000_drop_legacy_desktop_schema`), including scripts wired into `package.json` (`fresh-start:mobile`, `wipe:all-user-data`, `reset:all-accounts`, `migrate:moments`) and the "Quota hygiene" section of `DEPLOY.md` (`list-pending-stream-runs.ts`, `cancel-pending-stream-runs.ts`). They will crash at runtime. → Delete or update after confirming none are still needed.
5. **The three canonical vocabulary docs contradict each other and the schema.** AGENTS.md, GLOSSARY.md and ONTOLOGY.md disagree about the UI noun (chapter vs pursuit), the `Mark` entity (dropped vs schema-only), the status enum (`ABANDONED` was removed 2026-06-19), and the SQL layer (`bloomStatus`, `Branch`, `isSystemHub`, `hubTaxonomyVersion` were all physically renamed on 2026-06-12). Anyone — human or AI — following these docs will write wrong code. → Fixed in this PR (§6).

None of the findings indicate broken production *request* paths: API auth, ownership scoping, input validation and rate limiting are consistently applied (§4.1).

## 4. Code findings (report-only; not changed in this PR)

### 4.1 What's consistent (checked, no action)
- **Auth:** every non-public route resolves the user via `requireApiSessionUserId` (bearer JWT + cookie) or `getServerSession`; middleware additionally 401s all `/api/*` except `/api/auth/*` and `/api/health`, and forwards mobile bearer tokens as session cookies (unconventional but documented, `src/middleware.ts:47`).
- **Ownership:** goal-scoped routes consistently query `where: { id: goalId, userId }`; destructive `DELETE /api/goals/[goalId]/permanent` also requires prior archive.
- **Validation:** zod on all mutating routes spot-checked; JSON-parse guarded.
- **Rate limiting:** all five custom auth endpoints + `map/ai-sync` + `transcribe` are limited.
- **Gemini budget:** `MAX_GEMINI_CALLS_PER_SYNC = 2` matches DECISIONS.md.

## 5. Process observations

- **Supersession is one-directional.** Newer DECISIONS.md entries carefully annotate what they supersede, but the superseded entries below them are often left un-flagged (e.g. "Marks confirmed staying", the InsightCache design, monetisation copy referencing the retired Stream/Now tab). A reader starting from the bottom reconstructs a retired product.
- **Vocabulary migrations outpace the vocabulary docs.** The chapter rename shipped in code and AGENTS.md but never reached ONTOLOGY/GLOSSARY — the two files the repo designates as the naming source. The renames themselves (hub→category, bloom→status) were executed thoroughly *in code*; it's the docs that lag.
- **The repo's declared sources of truth live outside the repo** (§3). Any environment that only has `pathfinder/` — CI, cloud agents, a new contributor — cannot resolve the decision hierarchy.
- **Generated artifacts get committed** (`qa-quality-report.*`, debug screenshot) because `.gitignore` was updated after they were tracked.

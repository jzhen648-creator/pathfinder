# Changelog

## 2026-04-23

- Manual branch creation (Slice 1 — data + chooser UI): loaded canonical `Branch` records into client state (from `/api/branches` in real mode, from `MOCK_DATA.branches` in mock mode) and threaded `branchId` through `addQuickNode` / `commitPendingGuidedNode` so new moments can be bound to a specific Branch. Added a gap chooser popover that appears when clicking the root-area gap of a populated limb, offering "Add moment here" (existing behaviour) or "Start new branch" (creates a sibling Branch on the same Limb with a fanned `mapAngleOffset` via `computeNextBranchOffset`, then opens guided flow tagged to the new branch via `pendingNewBranchId`). Surfaced all branches in DevPanel under a new "BRANCHES (RAW)" section so new branches can be inspected immediately. Note: Slice 2 will refactor the render loop to visually fan sibling branches at their angle offsets; until then, new-branch moments persist correctly but render on the default limb trunk.
- Added optional `Moment.subtype` tagging (Option C for in-limb categorisation). The `People & Relationships` limb now ships a curated vocabulary (`family`, `friends`, `romance`, `community`) exposed via `LIMB_SUBTYPES` in `src/lib/types.ts`; other limbs keep empty vocabularies for now. Extended the `Moment` Prisma model with a nullable `subtype` column (`npx prisma db push` applied), wired `/api/moments` POST and `/api/moments/[id]` PATCH to accept and persist `subtype`, propagated `subtype` through the mock/load pipeline in `pathfinder-home.tsx`, and added a compact “Category” chip picker in the moment detail panel that only appears for limbs with defined subtypes. Pre-tagged the 7 People mock moments with representative subtypes so the feature is visible immediately. No visual changes to the map itself.
- Introduced canonical life-map foundations: new `Self/Limb/Branch/Moment/TurningPoint/Path/Gap` type system, new `LIMBS` config, new `mock-data` branch+moment fixtures, and rewritten map geometry helpers (`buildPaths`, `buildGaps`, `calculateMapPosition`) based on `mapPosition`.
- Added new REST endpoints for canonical entities (`/api/moments`, `/api/moments/[id]`, `/api/branches`) and set `/api/goals` + `/api/goals/[goalId]` to `308` redirects for backward compatibility with existing clients.
- Reworked Prisma schema life-map persistence from legacy node/line models to `Branch` + `Moment` models (plus auth models), updated dev reset/node helpers to use `Moment`, and aligned mock toggle usage to `FLAGS.MOCK_DATA`.
- Removed year/month prompts from guided moment flow (now type -> describe -> done), defaulted guided-flow saves to `year = currentYear` and `month = null`, and added a subtle timeline hint (`Year not set — tap to edit`) for current-year moments with no month so users can correct dates later in the detail panel while map ordering remains `mapPosition`-driven.
- Implemented Option A depth-ring hierarchy in the life map (`RING_1`, `RING_2`, `RING_3`) and updated fork/prompt/node positioning to create clearer near-root branching and farther-out node placement.
- Updated sub-branch spreads for all five default branches (wider angle offsets) to fan sub-branches earlier and increase visual separation.
- Added branch/sub-branch focus state (`focusedBranch`, `focusedSubbranch`) with dimming/scaling of non-focused branches, clickable branch/sub-branch lines/labels, breadcrumb-style back navigation on-map, and a focused sub-branch edit toggle with lightweight node edit handles.
- Added Ring-2 `+ Add` affordances: always visible for empty sub-branches, and hover/focus-visible for populated sub-branches at an add point beyond the last node.
- Refined edge hierarchy rendering weights/opacities by semantic depth (`trunk`, `subbranch`, `node`) and removed development-only branch position/node count logging effects that were adding noise and avoidable render churn.
- Enabled `DRAG_TO_CONNECT` and implemented first-pass node drag interactions on the life map: drag start/move/end with mouse and touch, ghost edge + ghost node visuals past a distance threshold, branch-near highlighting and “Connect to …?” affordance, drop-to-open guided flow continuation on the same branch/subbranch, and drop-near-other-branch calls to `POST /api/life-map/drag-suggestion` with a lightweight suggestion toast.
- Added drag guided-flow context (`parentNodeId`, `parentLabel`, `parentYear`, `subbranch`, `promptOverride`) and applied it to guided prompt copy plus year-chip generation so year choices start from the parent node’s year during drag-initiated flows.
- Life-map branch visuals now render with explicit trunk/fork structure per default branch: shared trunk from root to fork (`TRUNK_RATIO = 0.35`), visible fork dot, and per-sub-branch lines from fork to first node (or empty endpoint) using sub-branch colours/opacities; node placement uses fork-based formulas (`getForkPoint`, `getSubbranchPromptPos`, `getSubbranchNodePos`) so sub-branches fan out instead of stacking on one line.
- Updated default branch sub-branch metadata to complete configs (ids, labels, colors, angle offsets, examples) for Finance, Work, Becoming, People, and Health; renamed people romance id to `people-romance` and finance decisions id to `finance-decisions`.
- Added clickable empty sub-branch endpoint prompts (dashed mini circle + tiny label + hover CTA) that open guided flow preselected to that sub-branch and skip type selection by jumping directly into the mapped flow.
- Updated mock data subbranch ids to match branch config (`people-romance`, `finance-decisions`) so seeded nodes render on intended sub-branches.
- **Life map pillars:** Removed the default **Where I've Been** branch and all places-specific guided flows, mock nodes, and map styling. Added **Who I'm Becoming** as a fifth default pillar (not unlockable) with sub-branches Mindset Shifts, Lessons Learned, and Identity Changes; rebalanced default branch angles to Finance −72°, Work −36°, Becoming −2° (centre), People 36°, Health 72°.
- **Location on nodes:** Optional `location` string on life-map nodes; guided flow now includes an optional “Where were you when this happened?” step after the main flow (before significance) on all branches; map labels show `📍` plus location under the title at 7px and 35% opacity in branch colour. Prisma `LifeMapNode.location` added; `GET /api/goals` and `PATCH` life-map node payloads support `location`.
- **Becoming guided flows:** Concrete step flows for Mindset Shift, Lesson Learned, and Identity Change (including free-text steps for personal answers).
- Mock data: removed all places-branch nodes; added **Moved to Bangkok** on People (`mock-move1`), three **Who I'm Becoming** nodes, and sample `location` values on listed work/health/people nodes; updated cross-node `connectedTo` references.
- Added feature flags `DRAG_TO_CONNECT`, `AI_DRAG_SUGGESTIONS`, and `NODE_CONNECTIONS` (all default false) for a future drag-to-connect and AI suggestion flow on the life map.
- Added position-aware line insertion on the life map: trunk clicks now segment to sub-branch selection by click band, sub-branch clicks now compute insertion index from click ratio (start/middle/end), and guided flow receives insertion context (`insertIndex`, adjacent node ids, contextual `promptOverride`).
- Added hover insertion affordance on branch lines: a snapped “Add here” marker (green dot + branch-colored halo/label) follows cursor on transparent hit lines and clears on leave/close.
- Updated quick-node creation to accept a `createdAt` override and derive insertion-aware timestamps so non-end inserts remain correctly ordered by `createdAt` and shift existing nodes outward without changing map geometry rules.
- Added development-only `DevPanel` overlay (`FLAGS.DEV_PANEL`) with live hovered-element inspector, selected-node payload viewer, map/perf stats, branch breakdown explorer, quick dev actions, and a gap-zone visualiser toggle.
- Added `DEV_PANEL` feature flag and map wiring for dev hover payloads (`node`, `gap`, `branch`, `subbranch`), temporary map highlight from panel item clicks, keyboard toggle (`Cmd/Ctrl+Shift+D`), and a bottom-left `DEV` pill toggle.
- Updated user-facing language across dashboard/life-map/dev panel flows to simplify wording from goal/node terminology to moment-oriented copy (buttons, labels, empty states, and panel headings) without changing variable/type/API identifiers.
- Simplified life-map MVP to five fixed branches with no subbranches/unlocks, linear createdAt-based moment stacking, root-aware centering with dev-panel width compensation, single-line branch edge behavior, and mock data aligned to branch-only moments.
- Added line-system scaffolding across geometry/types/schema/mock data (new `map-geometry` utilities, `Line` and `LifeMapMoment` type extensions, Prisma `Line` model + moment line fields, and mock line fixtures with `lineId` on moments), plus memoized component shell files for upcoming life-map split.
- Added `mapPosition` ordering support for life-map moments (schema + types + mock data), switched map ordering to `mapPosition` with midpoint insertion support, updated timeline ordering to year/month ascending, and added optional guided-flow month-part capture mapped to month buckets.
- Fixed map/timeline ordering separation by introducing explicit guided-flow insert context for gap clicks and mapPosition midpoint insertion math, enforcing map rendering order by `mapPosition` only (independent from year), while keeping timeline rendering year/month ordered.
- Added `src/lib/types.ts` with scaffold types `DragState`, `NodeConnection`, and `AIDragSuggestion` for that feature.
- Scaffolded drag-related state, placeholder drag handlers, and a gated SVG connection-line placeholder in `pathfinder-home.tsx`; renamed the existing guided-flow connection type to `GuidedFlowConnection` to avoid clashing with the new shared `NodeConnection` type.
- Added scaffold API route `POST /api/life-map/drag-suggestion` returning a mock suggestion and `scaffolded: true` when authenticated.
- Reworked unlock-branch floating prompt: dismiss actions persist (`pathfinder_dismissed_unlocks` for “Not interested”, session snooze for “Remind me later”), queue + 30s gate between prompts, 10s auto-dismiss with leave animation, richer layout (branch icon/name/sublabel, contextual insight copy for “Who I'm Becoming”, social hint, countdown bar), repositioned above Today’s Focus, and three-button actions (add / remind / not interested).
- Life map nodes: hover shows a compact preview card; click opens a right-hand detail panel (slide-in, dimmed map) with description, debounced reflection (`timelineNote`), connections, significance controls, mini timeline, edit/save, branch move, and remove-with-confirm; map nodes dim other points when one is selected and add hover scale plus a selected ring.
- `GET /api/goals` now returns persisted `lifeMapNodes` from Prisma; `PATCH /api/goals/[goalId]` supports field updates for life map nodes (and basic goal field updates when the id is a goal) while preserving the existing conversation-based goal edit flow.
- Fixed runaway re-renders: `PerfMonitor` no longer calls `setState` on every commit (ref-count + throttled display); suggestions and dev logging effects no longer depend on a freshly allocated `timelineGoals` array each render; unlock-queue orchestration depends on `goals.length` instead of the full `goals` reference.
- Life map geometry: shared trunk to a fork point (`PROMPT_DISTANCE * 0.4`), sub-branch nodes placed from fork along per-sub angles (`0.6 * PROMPT_DISTANCE + index * NODE_SPACING`); edges draw one trunk curve, fork→first node, then node-to-node chains; decorative baselines skip duplicate trunk when sub-branches exist. `addOriginNodes` / `deduplicateNodes` drop synthetic `origin-born-living-place` when a `places-roots` node already exists (removes duplicate London story with mock “Grew up in London”).

Wiring in `tree-render-goals-subtree.tsx` / `tree-svg.tsx`.
- **Milestone symbolic completion:** Prisma **`Milestone.completedAt`** (nullable) + migration `20260511143000_add_milestone_completed_at`. Shared semantics **`milestoneDoneForSemantics`** (`src/lib/milestone-semantics.ts`) — explicit timestamp wins; transitional dual-read = all subtasks complete only when **≥1** subtask; **removed vacuous “0 subtasks ⇒ complete”** for lifecycle, projection, and roadmap. **`PATCH /api/goals/[goalId]/milestones/[milestoneId]`** toggles completion and triggers **`recomputeGoalBloomStatus`**.
